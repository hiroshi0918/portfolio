# portfolio

寺嶋 裕のポートフォリオサイト（静的 HTML / CSS / JS）。

想定公開 URL: **https://hiroshi0918.github.io/portfolio/**

## ローカルで開く

アセット・内部リンクは GitHub Pages のプロジェクトサイト用に `/portfolio/` ベースです。

```bash
./serve-local.sh
# → http://localhost:8080/portfolio/
```

`index.html` をファイルとして直接開くと CSS/JS が 404 になります。

## GitHub Pages

1. `https://github.com/hiroshi0918/portfolio` の `main` に push
2. Settings → Pages → Source を **GitHub Actions**
3. https://hiroshi0918.github.io/portfolio/

## 構成

Hero / About / Works（ココロパレット · Grow）/ Talks / Career / Contact。技術スタック一覧やスキルグリッドは載せていません。
