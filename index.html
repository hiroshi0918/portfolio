ココロパレット

リポ名: cocolog

日々の出来事と感情を記録し、振り返るセルフケアアプリ。 感情パレット・音声/テキスト入力・振り返りノートを備え、AI はオプトインで利用できます。

  • 感情記録・音声/テキスト入力・日本語約60語の感情パレット
  • 振り返りノート・カレンダーなどプロダクト実装一式
  • AI オプトイン設計（同意なしでもコア機能は利用可）
  • dev / prod / Emulator 環境分離、App Store 提出までの一連
React Native (Expo) TypeScript Firebase Claude Whisper
App Store GitHub (Private)

リード向け: 実ユーザー向けに公開したアプリ。モバイル・BaaS・AI API・プライバシー配慮まで一通り見られます。

Web プロダクト Full-stack · SaaS

Grow

リポ名: grow

小学生が「教える」体験を通して自己肯定感と説明力を育てるオンラインサービス。 保護者が契約主体、子供はサブプロフィール。

  • 保護者・子供・大人（先生役）・運営の多ロール認可設計
  • 子供は PIN + 署名付き JWT（Supabase Auth を持たない）など認可の作り分け
  • LiveKit 授業 + 録画 Egress + AI ハイライト生成
  • Stripe サブスク（webhook 冪等化）と録画90日パージ等の運用設計
Next.js 16 Supabase Stripe LiveKit OpenAI Vercel Cron
GitHub (Private)

リード向け: 画面だけでなく認可・課金・非同期処理・データ保持まで設計。マネージドサービスを組み合わせた現代的な構成です。
